# Design Delta: CR-001

## User flow

1. 打开应用 → 素材库（空态：提示拖拽/选择文件导入，或加载内置样本）。
2. 导入素材（拖拽或文件选择）→ 按类型分类出现在网格 → 可筛选/搜索。
3. 点击素材 → 主区域打开对应查看器：
   - 图片：预览 + 双图比较；
   - DICOM：元数据面板 + 切片预览（无压缩时）；
   - 3D：Three.js 查看器（旋转/缩放/平移）。
4. 评审面板（侧栏/底部）：状态（待评审/通过/驳回）、标签、备注、AI 建议（Mock）→ 保存。
5. 导出 JSON（可追溯评审记录）→ 或导入 JSON 恢复。

## Screens and states

| Surface | Default | Loading | Empty | Error | Success |
|---|---|---|---|---|---|
| 素材库网格 | 全部素材 | 导入中骨架 | 空态引导（拖拽/选择/加载样本） | 导入失败提示 | 素材卡片显示 |
| 图片查看器 | 单图预览 | 图片加载中 | — | 图片损坏提示 | 正常显示 |
| DICOM 查看器 | 元数据面板 | 解析中 | — | "无法解析，仅元数据/降级" | 元数据+切片预览 |
| 3D 查看器 | 模型居中 | 加载进度条 | — | 加载失败提示+重试 | 可交互模型 |
| 评审面板 | 当前状态 | — | 无历史 | 保存失败提示 | 保存成功反馈 |
| 比较视图 | 双图并排 | 加载中 | — | — | 双图显示+退出按钮 |

## Interaction and accessibility

- 全部操作用鼠标即可完成；比较视图提供明确"退出比较"按钮。
- 筛选条件（类型/状态/标签/搜索）为并列控件，变更即时生效，支持组合。
- 状态徽标使用颜色区分（待评审=灰/黄、通过=绿、驳回=红），辅以文字而非仅颜色。
- 键盘：素材卡片可 Tab 聚焦；Esc 关闭比较视图与弹层。
- 响应式：窄屏时评审面板折叠为抽屉。
- 所有弹层/提示含明确错误与成功文案；AI 建议面板明示"Mock 生成"。

## Design constraints

- 语言：中文界面。
- 单页应用，无路由库（单视图 + 模态），保持轻量。
- 样式：手写 CSS（CSS 变量），不引入 UI 框架，控制依赖面。
- 医疗相关界面不得出现诊断/治疗暗示文案。
